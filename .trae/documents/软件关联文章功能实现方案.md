## 软件关联文章功能实现计划

该计划旨在为每个软件集成相关文章链接（如文档、技巧、FAQ、更新日志），包括数据库扩展、后端 API 开发、后台管理界面及前端展示。

### 1. 数据库设计与迁移
- **方案选择**：在 `softwares` 表中新增 `related_articles` 字段（JSONB 类型），存储文章链接数组。
- **数据结构**：
  ```typescript
  interface RelatedArticle {
    id: string;
    title: string;
    url: string;
    type: 'document' | 'tips' | 'faq' | 'changelog' | 'other';
    description?: string;
    sortOrder: number;
    createdAt: string;
  }
  ```
- **执行步骤**：
  1. 提供 SQL 脚本用于手动或通过脚本添加列：`ALTER TABLE softwares ADD COLUMN related_articles JSONB DEFAULT '[]'::jsonb;`

### 2. 后端 API 开发 (`server/index.js`)
- **Schema 校验**：更新 `verifySchema` 函数，包含对 `related_articles` 列的检查。
- **CRUD 增强**：
  - 更新 `POST /api/software`：支持接收并存储 `related_articles`。
  - 更新 `PUT /api/software/:id`：支持更新 `related_articles`。
- **新增接口**：
  - `GET /api/software/:id/articles`：专门用于获取指定软件的所有关联文章。
